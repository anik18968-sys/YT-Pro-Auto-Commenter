# YT Pro Auto Commenter

A lightweight and advanced Chrome Extension to automate comments on YouTube Live streams. It is designed with anti-spam features to prevent your account from getting restricted.

## Features
* **Anti-Spam Bypass:** Automatically appends random emojis to each comment to make them unique.
* **Randomized Delays:** Comments are sent at random intervals (between 1 to 5 seconds) to mimic human behavior.
* **Floating UI:** Control the bot directly from the YouTube Live chat screen using the floating `START BOT` / `STOP BOT` button.
* **Local Storage:** Saves your comments automatically so you don't have to retype them.
* **Auto-Clear Input:** Prevents duplicate text glitches by clearing the chat box before pasting new comments.

## Installation Guide
1. Download this repository as a ZIP file and extract it to a folder.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Turn on **Developer mode** (toggle switch in the top right corner).
4. Click on the **Load unpacked** button.
5. Select the folder where you extracted the files.

## How to Use
1. Go to any YouTube Live stream.
2. Click on the extension icon from the top right of your browser.
3. Type your comment and click **SAVE**.
4. Click **START** from the extension popup, OR click the floating **▶ START BOT** button directly on the YouTube page.
5. To stop, click the floating **⏹ STOP BOT** button.
